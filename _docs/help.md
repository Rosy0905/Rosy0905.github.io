# 主站使用帮助 · 数据与储存说明

这份文档讲一件事：四个站的数据分别存在哪里、清空会删掉什么、为什么有时候"清完了还显示有数据"。

---

## 一、先说大局

四个站（经济学、数三、阅读、单词）都挂在同一个域名下，浏览器给它们**共用同一套本地储存**：

- **localStorage**：存小块的键值对，比如收藏列表、进度、各种偏好设置
- **IndexedDB**：存大块的结构化数据，比如数学题库、阅读笔记

主站（学习主页）自己不产生学习数据，它是这四个站的**大管家**——导入、导出、代清都通过右上角花心里的三个小球完成。

## 二、三个小球分别干什么

| 小球 | 作用 | 说明 |
|---|---|---|
| 导入球 | 把备份文件写回四个站 | 选文件后按站恢复，本机已有的 AI 密钥不会被覆盖 |
| 导出球 | 把四个站的数据打成一份 JSON | 默认全选，弹窗里可以只勾某几个站 |
| 清除球 | 删掉勾选站的数据 | 删之前弹窗会列出每个站有多少条记录 |

## 四、两种"清空"不是一回事（最容易晕的一块）

**站内清空**：在某个站自己的页面上点清空，只清那个站**自己认为该清的东西**。
**主站代清**：在主站清除弹窗里勾选，按前缀表**整个站的数据全删**。

对照表：

| 站点 | 站内清空删什么 | 主站代清删什么 |
|---|---|---|
| 经济学 | 勾选模块的前缀键 + 进度三件套（`eco_kb_progress`、`eco_kb_progress_at`、`eco_kb_tts_rate`）。AI 四类、我的卡片**不删**，它们各有自己的清空入口 | 上面所有键，**包括** AI 四类和我的卡片 |
| 数学三 | 只有"清空正误"一个按钮，删 `status` 表，题目保留 | 和站内完全一样：只清 `status` 正误表，题库和版本号都不动 |
| 英语阅读 | 全部键 + 两个笔记库，但**保留 `ekz-wiped-` 记号** | 同上，**同样保留记号** |
| 单词速刷 | 五个 `dkz.` 键全删 | 同左 |

所以有两件事是正常的，不是bug：

1. **经济学站内清完之后，主站还显示一批数据**——那是 AI 配置、AI 卡片、我的卡片，站内设计就是分开清的，想全清就用在主站代清，或者去站内点各自的清空按钮。
2. **数学站清完正误，主站还显示一堆题目**——不会出现这种情况了。主站把数学站的"数据"定义成了和站内一致，正误表才算记录，题库是内容不计入条数。代清数学站只清 `status` 表，题库和版本号原地不动，清完就是清完。

## 五、`ekz-wiped-` 记号是什么

阅读站清空数据时，每清掉一条记录会留一个 `ekz-wiped-<id>` 的记号键，里面只有一个时间戳。这是阅读站自己的**防复活机制**：如果清空时还有别的标签页开着，那些页面内存里存着旧笔记，可能会在关闭时把旧数据写回来。记号用来拦住这种写回，否则就会出现"清空了，数据又复活"。

记号不是学习数据，所以主站**收集、导出、计数、代清四处都跳过它**——你之前在清除弹窗看到阅读站"还有 7 条"，就是这 7 个记号被当成了缓存数据，现在已经修掉了。主站代清阅读站时也会把记号留下，不破坏它的防复活机制。

## 六、弹窗里的"条数"怎么算

每个站显示的记录数 = localStorage 键数 + IndexedDB 各表的记录数。两个例外，记号键和题库表都不计入——它们不是学习数据。体积（B）是这些数据的实际大小估算。

具体到数学站：只数 `status` 表的记录数，几百道题的 `problems` 表不计入，所以条数就是"标记过几道题"。

## 七、备份（导出）包含什么

- 四个站的 localStorage 键（记号除外）+ 各站数据库里的学习数据
- **数学站例外**：备份只带 `status` 正误标记，题库不进备份。题库是随站内容，换电脑后打开数学站会按版本号自动重灌，不用担心丢题
- AI 配置导出时**自动剔除 API Key**，防止备份文件泄密；导入时保留本机已有的 Key，不会被备份里的旧值覆盖
- 备份文件是纯 JSON，建议每次大改动前导一份，换电脑/清浏览器之后导入就能还原

## 八、常见问题

**Q：主站代清数学站，题库会不会被删没？题库会受影响吗？**
不会。主站代清数学站只清 `status` 正误表，`problems` 题库和 `studyMathSeedVer` 版本号都不碰，和站内"清空正误"是同一个动作。题库是随站内容，本来就不在清除范围里。

**Q：清除弹窗里某个站不显示？**
那个站当前没有数据（计数为 0），列表只渲染有数据的站。

**Q：导入备份会覆盖我现在的新数据吗？**
localStorage 键和数据库记录都是按备份内容覆盖写入。导入前如果想保险，先导出一份当前状态。

**Q：为什么经济学站自己页面导出的备份，和主站导出的内容不一样？**
基本一样，两个差别，① 经济学站自己的导出弹窗里，AI 对话历史和 AI 配置是可选项（默认不勾），主站导出默认全带上，② 两边都会自动剔除 API Key。日常备份用哪个都行，主站更方便，四站一把出。

**Q：阅读站自己清空了，主站还显示有数据？**
先看条数是不是和记号数量对得上（第五节）。对不上的话，可能是平板自检面板的日志——它不是学习数据，但带阅读站的前缀，主站会把它数进去。主站代清能连它一起删掉，阅读站自己的清空现在也会删它。
