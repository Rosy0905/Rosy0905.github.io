📤 导出数据

勾选需要备份的站点，四个站的数据会打成一个 JSON 文件。AI 配置里的 API Key 不会写进文件。

📥 导入数据

备份里带的记录会整块覆盖本机对应数据，本机有、备份里没有的不动。AI 配置会保留本机已有的 API Key。

🧹 清除数据

勾选要清空的站点。清除后不可恢复，建议先导出备份。对应站点的学习记录会被删掉，AI 配置里的 API Key 也会一起清掉。

⚠️ 确认清除
